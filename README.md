# Turtle Celebration

自作EP「Turtle Celebration」の世界観を体験する、スマホブラウザ向けの探索型 /
コンテンプレイティブ・ディオラマ。明確な失敗条件はない。PixiJS v8 + Vite。

```
npm install
npm run dev      # http://localhost:5173/  (横向き推奨)
npm run build
```

## 操作・世界の考え方

- **左右タップゾーン操作**(`systems/FlightController.js`): 前進速度は常に一定。亀は
  画面上の一定 X に留まり、背景がスクロールして前進を表現する。プレイヤーは縦だけ:
    - **画面右半分を押す** = 上昇方向へ加速
    - **画面左半分を押す** = 下降方向へ加速
    - **無入力** = 重力なし。垂直速度を減衰させてその高さを維持
  - **潜水チャージ & 段階リープ**: 下入力を保持すると画面の底(水面ライン + 29%)へ沈み、
    底で保持し続けた秒数がパワーになる(`flight._charge`、最大 `chargeMaxSec` 3秒 =
    tier 1/2/3、`chargeTierSec:[1,2,3]`)。溜まっている間は `scene/ChargeAura.js` の
    3段階エフェクト(発光・膨張リング・下から昇る光条・tier3 は周囲の水が放射状に暗く締まる)。
    下入力を離す(or 上を押す)と `leapImpulseByTier` に応じた勢いで水面から飛び出し放物線を描く
    (`flight.leapTier` で飛沫 + SFX、放物線はブリーチ機構を流用、着水で浅く受け止める)。
    tier 0(< 1秒)は小さくちょっと跳ねる、tier 3 は高く飛ぶ。
  - **滑空**: 高所を無入力でいると前進がわずかに伸びる(`flight.glideMaxBonus`)。
  上下限はシンプルな非対称のソフト壁(上=画面上端付近、下=水面ライン + 29%)。
  ↑/W = 上昇、↓/S = 下降のキーも可。上昇中は亀の後方に速度線 2〜3 本。
  傾きは maxTiltRad(既定 0.22rad)を tanh で飽和、絶対に超えない。
  ゲーム開始直後に「← 下降 / 上昇 →」を数秒だけ表示(セッション中1回、フェード)。
  上下操作の瞬間、最前面の水面帯のスクロールにバネ的な遅れを加える(水を掻く抵抗感)。
  控えめ・ゆっくり(`sea.inputKickPx` / `inputSpringStiffness` / `inputSpringDamping`)。
- **進行方向は右→左で統一**: 世界・光のオーブ・生き物(イルカ/小魚/マンタ/クラゲ)は
  すべて画面を右から左へ流れ、左を向く。亀だけが前(右)を向いて泳ぐ。
- **時間帯サイクル**: 1ラン = 一本道(朝→昼→夕→夜)。ループなし。長さは BGM
  (15分39秒 = 939秒、`turtle-celebration-bgm.mp3`)に合わせてある。色遷移は ease-in-out。
  `timeOfDay.loop:false` で progress は 1 で頭打ち。
- **光のオーブ → ブーケゲージ**(`systems/BouquetGauge.js`): 一定間隔で右から流れてくる。
  近づくと自動収集(タップ不要、光のバースト)。収集で左上のゲージバーが溜まり、満タンで
  亀の甲羅の上のブーケが1段階進む(なし → つぼみ → 小さな花束 → 満開、`deco-bouquet-1/2/3.png`)。
  3段でカンスト。収集は夜空の星の蓄積にも寄与。数値表示はしない。
- **小さな演出**: オーブ収集の光バースト / クラゲが亀に近づくと発光が強まる。
  オーブは下寄り(水面〜潜水域)にも一定割合で出現し、自発的に潜る動機付けにする。
- **コンテンプレイティブな上達要素**(`config.contemplative`。すべて失敗要素ではなく
  "気持ちよさ"のため。数値表示なし・視覚と音だけ):
    - **スリップストリーム**(`scene/Slipstream.js`): ランダムな高さに光の粒の帯が流れる。
      内側にいる間だけ前進が加速し、BGM のローパスが開く(`bgm.setBgmFilter`)。
    - **上昇気流**(同 `Slipstream`、`kind:'updraft'`): 縦の光の柱。中を通ると上向きの
      ゆるいリフト(`flight.addUpdraftLift`)= ラクに高度が取れる。
    - **小魚の群れが割れる**: 亀が近づくと小魚が周りを避けて泳ぐ(`CreatureLayer.schoolAvoid`)。
    - **水面スキム・ボーナス**: 水面すれすれを一定時間維持すると、連続した飛沫 +
      オーブ収集半径が一時的に広がる(`orbs.setCollectRadiusScale`)。
    - **環境の微反応**: 亀が近くをかすめると、マンタは一度バンク / クラゲは強く脈動
      (`CreatureLayer` の `react`。クールダウンあり)。
    - **オーブフロー・チェイン**: 短時間に連続収集すると収集チャイムが半音ずつ上がり、
      航跡がわずかに増える・長持ちする。途切れるとリセット(`OrbField._chainLevel`)。
- **潜水中のビネット**: 潜るほどビネットの不透明度が上がり、色が濃い青(#0A1230)へ
  遷移 = 水圧・深さの感覚。
- **レア演出**(`scene/RareEvents.js`、`config.rareEvents`): 1ランに 1〜3 回だけ、
  抽選で起きる特別な景色。毎回少し違う = リプレイの意味づけ。
    - **クジラのブリーチ**: 水平線でクジラが飛び出して着水(海の奥)。
    - **通り雨**: グレーの veil + 雨脚がスクリーンを横切る。くぐると BGM がこもる(最前面)。
    - **流星群 / 流れ星**: 夜〜結婚式会場が現れる直前。`SkyLayer` に委譲。
- **音声**(`systems/audio.js`): `<audio>` → MediaElementSource → **AnalyserNode** →
  bgmGain → 出力。ミュートは bgmGain を 0 にするだけ(再生・帯域解析は止めない)。
  タブ復帰時は 0 → 目標値へ 1.6 秒フェードイン。Web Audio 不可の環境は el.volume 直制御へ縮退。
- **合成 SFX**(`playSfx`, Web Audio のオシレータ/ノイズ/フィルタ。録音なし・イベント時のみ・
  BGM より小さい): 潜水(ノイズ + ローパス下降スイープ)/ オーブ収集(短いサインのチャイム、
  semis で半音上げ = orb chain 用)/ ヨット通過(バンドパスノイズのスウェル)/
  飛行機通過(低ノコギリ + ノイズ、ドップラー的な音量・ピッチ変化)。
- **音楽の帯域別振幅リアクティブ**(`sampleBands`, config `audioReactive`): 各帯域の
  「緩やかな平均からのズレ」を毎フレーム算出。low(20–150Hz)→太陽/水平線の明るさ ±、
  mid-low(150–500Hz)→波の振幅、mid-high(1–4kHz)→羽ばたき速度 ±、
  high(4–8kHz)→オーブの明滅。すべて控えめ・クランプ付き。
- **結婚式のクライマックス**(`scene/WeddingClimax.js`): EPは制作者の姉の結婚式
  (ハワイ)のための曲。スケジュール制の一本道(「亀を島へ誘導」は廃止):
    - `idle` 通常巡航 → `incoming`(進行度 85%)で会場が右から流れて近づく。操作は通常通り。
      `deco-wedding-venue.png`(花嫁アーチ)/ `deco-wedding-island.png`(専用の島)。
    - `arrival` 到着ビート(数秒・自動・入力不可)。ブーケが甲羅から消え、光の粒とともに
      `deco-couple.png` の傍らへ。ゲージ未達なら受け渡し演出はスキップ(エラーにしない)。
      前進はここで 1→0。
    - `epilogue` ワールドスクロール停止・時間帯も停止。亀がアーチの前をゆっくり旋回、
      花びらが舞う。入力不可。
    - `done` → 終了画面(ループなし)。
- **終了画面**(`ui/overlay.js` `showEnding()`): BGM を ~1.8 秒フェードアウト、
  `assets/ending-key-visual.png` へクロスフェード、締めのテキストがフェードイン、
  「もう一度みる」= リロード(常に朝から / 進行の永続化なし)。

## ビジュアル方針(Pinterest ボード準拠)

Alto's Odyssey のフラットさは保ちつつ、色数を使って"おしゃれ"に。参照ボードは
「青いウミガメの浜辺」「サンセットの泉」「Music of Hawaii」「Morena do Mar」など。

- **多層の波打つ海**(`SeaLayer`): 単一平面ではなく、ゆるく sin 波打つ横帯を5枚重ね。
  浅い帯は明るく(→白)、深い帯は暗く(→deepColor)。上2帯に白い泡ライン + 飛沫。
  波帯は水面ラインより `sea.frontOffsetRatio` だけ下げて始め、その上の隙間に
  **遠景の海**(`SeaLayer.distant`)を敷く: 空と同じ縦グラデ技法で、水平線側は空の
  水平線色(霞んで明るい)、前景の波に近づくほど海色へ。波紋の質感はなし。
- **雲の3層**(`decorLayers` の `cloud-far/mid/near`, depth 0.08/0.15/0.22): 奥ほど
  小さく淡く、手前ほど大きく時間帯の色をしっかり拾う。
- **空気遠近法(共通ルール)**: depth を持つ装飾は `atmosphereAmount(depth)` で
  自動的に霞色(= 空の水平線色)をブレンド。遠いレイヤーほど強く霞む。島影・雲・
  沿岸ヴィスタ・スプライト装飾すべてに同じ規則で適用(`def.hazeAmount` で上書き可)。
- **沿岸ヴィスタ**(`CoastalVista`, depth 0.5): ヤシ・崖・崖上の街・フラダンサー・
  トーテムを固定構図プリセット(cliff-town / rock-palm / beach-palms / hula-beach)で
  まとめて配置し、数分に1回だけ右→左に流す "通りすがりの特別な景色"。砂浜は
  コード描画の浅い曲線帯。アセットの余白は bbox で trim して水面ラインに正しく載せる。
- **形状ライブラリ方式 + ベジェ補間**(`scene/shapes.js`): ランダム多角形生成はしない。
  手作りのプリセット(制御点データ)を並べ、**島と雲は「同グループの2プリセット + mix」で
  線形補間**して中間形をつくる(#14)。珊瑚は離散のまま。
    - `ISLAND_PRESETS`(6種、バンプ数でグループ分け): 双耳峰 / 主峰+肩 / 単峰×2 / 三峰 / 長尾根
    - `CLOUD_PRESETS`(4種、全て4ブロブ = 任意の2つを補間可)
    - `CORAL_SHAPES`(7種): テーブル×2 / 枝×3 / ソフト×2(離散)
  さらに島影は確率 `spriteChance`(既定 0.33)で **`deco-island-1/2.png` スプライト**も
  変種として選ぶ。時間帯パレット(`tones.mid`)へ tint、空気遠近法込み。
  さらにスケール・左右反転・明度ジッター・軽い回転(`DecorLayer`)。
  各シェイプは 明(mid)/暗(dark) の 2 段 + 内側に等高線のような薄い曲線を 2〜3 本
  (参照: island-linework-reference)。等高線もバンプに従うので補間形に自動でついてくる。
- **飛行機**(EPコアモチーフ): 空レイヤーに低頻度で小さなシルエット + 点線の飛行機雲。
  `CreatureLayer` の `phase:"always"`。
- **オープニング**(`ui/overlay.js`): 専用キービジュアル1枚絵 `turtle-opening-hero.png`
  (Morena do Mar 参照、紺 + クリーム + ゴールド)を全画面に敷き、タイトルと
  「タップして開始」を重ねる。コード描画のオープニングは廃止。タップで BGM + サイクル開始。
- **前景の植物フレーム**(`FoliageFrame`): 四隅からヤシの葉・モンステラ・南国の葉が
  差し込み、間にプルメリア/ハイビスカス/ブーゲンビリアの花。葉は時間帯の暗い
  シルエット、花は明るいまま = 色のアクセント。ゆっくり揺れる。
- **様式化した太陽/月**(`SkyLayer`): 太陽 = 芯 + ずらした同心リング。月 = クレーター +
  光輪。星は大きさまちまちの斑点 + 4輝の star。
- **フィルムグレイン**(`GrainOverlay`): 画面全体に薄いノイズ(blend: overlay)。

## 描画順(奥→手前)

`backgroundTint` → 空(+流星) → 飛行機 → 雲3層(遠→近) → 島影 → 遠景の海(水平線の霞) →
クジラのブリーチ → 沿岸ヴィスタ → 結婚式(島/アーチ/カップル) → **海(波帯)** → ヨット →
珊瑚礁 → カニ/ロブスター → マンタ → 小魚(teal/yellow) → クラゲ → 光の流れ → 影 →
パーティクル → 速度線 → 亀
→（ここから worldContainer の外）潜水ティント → オーブ → ビネット →
**前景の植物フレーム** → 通り雨 → グレイン。

珊瑚礁は海の帯の手前(= 浅瀬に立つ姿)、水面ラインより下に配置。クラゲも手前で光る。
亀は前景の葉の奥を通る。

## 長時間セッション対策

- **プーリング**: 珊瑚・島・雲・生き物・沿岸ヴィスタ・パーティクル・オーブは画面外へ
  出たものを破棄せず再利用。生成し続けない。
- **ループ廃止**: 1ラン(15:39)で完結 → 終了画面。周回による状態リセットは無い。
- **座標の折り返し**: GPU に渡すスクロール量は `world.coordinateWrapPx` で剰余を取り、
  f32 の精度落ちによるガタつきを防ぐ。巡航距離の論理値(JS number = f64)はそのまま。
- **タブ非表示時**: Page Visibility API で ticker と BGM を停止。
- **色味ジッター**: 繰り返し生成される装飾は生成のたびに明度を ±数% ずらす。

## 実素材・音源について

- **亀(4パーツ)は接続済み**。`Turtle.js` の `PIVOTS` が制作側共有の回転中心。
- **珊瑚・島影・雲は `scene/shapes.js` のコード描画**(形状ライブラリ方式)。
  **生き物・乗り物・人物・沿岸/結婚式のアセットは `src/decorations/deco-*.png`**
  (Midjourney 生成、`textureTrim.js` で余白をクロップして使用)。
- **終了画面のキービジュアル**: `src/assets/ending-key-visual.png`。
- **BGM**: `public/bgm.mp3`(= `turtle-celebration-bgm.mp3`、15分39秒 の連続音源)。
  時間帯サイクルの `durationSeconds` もこの 939 秒に合わせてある。差し替える時は
  `config.json` の `audio.src` と `timeOfDay.durationSeconds` の両方を。
  未配置でもゲームは動く(無音で続行)。

## スコープ外(後日)

- PWA manifest(ホーム画面追加)。manifest.json を1枚足すだけで対応可能なため優先度低。
- localStorage による進行保存はしない(再読み込みで常に朝から)。
