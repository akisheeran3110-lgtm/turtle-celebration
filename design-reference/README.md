# design-reference/

実装には**使わない**視覚の参考資料置き場。ビルドにもバンドルにも含まれない
(`src/` の外にあるため Vite は無視する)。

## 運用ルール

- **Claude Code はこのフォルダを自動では参照しない。** 見てほしい時は明示的に指示する:
  例)「`design-reference/akinori_saito_screenshot...1.png` を見てから水面の色を調整して」
- 参考画像を追加したら、下の一覧に1行ずつ足す(ファイル名 — 何の参考か)。
- 「この画像そっくりに作れ」ではなく「方向性の擦り合わせ」に使う。最終判断はゲーム内で
  実際に動かして見た印象。

## いま入っているもの

- `pinterest_743094007311441438.pdf` — Pinterest ボード(39p)。青いウミガメの浜辺 /
  サンセットの泉 / Music of Hawaii / Morena do Mar 等。全体トーンの母体。
- `akinori_saito_screenshot..._1.png` / `_2.png` — 横長モバイルゲームのスクショ調キービジュアル。
  レイヤー感・色数・観光ポスター調の目標イメージ。
- `akinori_saito_digital_illustration_of_a_sea_turtle_gliding..._0 (1).png` — 亀のグライド作画の参考。
- `29c2229c-....jpeg` — 補助の色・構図参考。
